
A brief description of the mobile application and its purpose.

# Features Highlight


Interactive Question Cards: Dynamically rendered quiz questions with rich visual assets, custom typography, and dropdown selection menus.
Score Tracking & Dynamic Alerts: Automated score calculation triggering customized native pop-up alerts based on user performance.
State Reset: Clear-and-retry functionality allowing users to reset all selected answers and submission states to attempt the quiz again.
